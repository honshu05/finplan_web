# Finplan v2

An interactive, high-performance financial planning and simulation suite built with React 19, TypeScript, Tailwind CSS, and Vite.

## Features

- **Interactive Financial Simulation & Forecasting**: Dynamic real-time wealth trajectory and cash flow simulations.
- **Rebalancing Target Optimization**: Automated optimization of debt/equity/alternative rebalancing triggers.
- **Scenario Stress Testing**: Multi-decade inflation, market drawdown, and expense shock scenarios.
- **Interactive Visualizations**: High-fidelity charts powered by Recharts.
- **Client-Side Exporting**: Instant PDF and summary exports.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons & Charts**: Lucide React, Recharts
- **Deployment**: GitHub Pages via GitHub Actions

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Create production build
npm run build
```
